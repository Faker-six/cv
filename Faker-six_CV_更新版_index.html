個人簡介｜About Me

目前就讀於國立陽明交通大學科技管理研究所，主要研究領域為醫學影像分割（Medical Image Segmentation）、深度學習與電腦視覺，專注互動式醫學影像分割、支援條件式分割、醫學影像基礎模型及模型特徵融合。

研究成果獲 ECCV 2026 Medical Foundation Models and Benchmarks (MEDFMB) Workshop 接受（Accepted）。除醫學影像分割外，亦研究 Diffusion Models、醫學影像生成、3D CT Segmentation、Continual Learning 等主題。曾於富萱科技實習，並與樂達創意科技股份有限公司合作，累積學術與產業實務經驗。

研究專案｜Research Projects

01｜互動式醫學影像分割

Interactive Medical Image Segmentation · PyTorch · MultiverSeg · CNN · Attention

  • 研究單點及多點互動分割，結合 Query Image、Support Image、Support Mask 與點提示等資訊。
  • 探討 Large-Kernel Convolution、Spatial Gating、Channel Attention 與 Feature Fusion。
  • 使用超音波及內視鏡影像資料集，比較不同互動條件下的 Dice、IoU 與 AUC。

02｜醫學影像生成與擴散模型

Medical Image Generation · Latent Diffusion · Stable Diffusion · DDIM

  • 研究乳房超音波影像生成與重建，並探討 Speckle、Attenuation 等物理先驗。
  • 使用 FID、KID、PSNR、SSIM、MS-SSIM、LPIPS 等指標評估影像品質。

03｜3D 醫學影像分割

3D CT Segmentation · nnU-Net v2 · ROI · Multi-rater Annotation

  • 研究胰臟癌血管侵犯相關 CT 資料的 ROI 分割及多標註者整合。
  • 使用 nnU-Net v2、STAPLE 共識標註及 3D 分割評估流程。

04｜持續學習與高效率訓練

Continual Learning · L2P · DualPrompt · CODA-Prompt · Zeroth-Order Optimization

  • 探討循序學習下的災難性遺忘、Prompt Learning 與模型記憶效率。
  • 研究零階最佳化技術於高效率訓練的潛在應用。

Audio Classification · Signal Processing · MFCC · SVM · Python

06｜基於最佳化線性融合之夜間影像強化方法

共同作者專題

Computer Vision · Image Enhancement · Histogram Equalization · Metaheuristic Optimization

  • 共同參與夜間影像增強研究，融合原始影像與直方圖均化後影像，以改善低照度影像的對比與細節呈現。
  • 採用基於區塊的對比度品質指標（PCQI）評估影像增強效果，研究以啟發式最佳化方法尋找線性融合權重。
  • 專題文件比較傳統直方圖均化及 CLAHE 等方法，並以影像實驗評估效果。
